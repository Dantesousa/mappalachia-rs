# Egui GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `crates/egui` — a native eframe window: search → results → items-to-plot → settings → background-thread preview → export PNG/JPG + recipe open/save. Standard plot mode only (Topo/Heatmap/Cluster arrive in the modes plan; the mode selector shows Standard locked with the others greyed).

**Architecture:** `egui` depends on `core` + `render`. App state is plain data (testable without an event loop); rendering runs on a worker thread via `std::sync::mpsc` (a 4096² render takes seconds — never block the UI thread); finished Pixmaps upload as `egui::TextureHandle` (`ColorImage::from_rgba_unmultiplied`). Assets/DB paths come from env (`MAPPALACHIA_ASSETS`, `MAPPALACHIA_DB`) with a config line in the window when missing.

**Tech Stack:** eframe 0.32 (adjust to a version compiling on rustc 1.99 if needed, document it), core + render crates.
